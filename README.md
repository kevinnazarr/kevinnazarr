# 💫 About Me:
Saya adalah Fullstack Developer yang berfokus pada pengembangan aplikasi web modern dengan pendekatan yang rapi, scalable, dan mudah dipelihara. Saya terbiasa mengerjakan sisi frontend maupun backend, mulai dari membangun antarmuka yang responsif hingga merancang API, database, autentikasi, dan workflow aplikasi.<br><br>Saya tertarik pada bagaimana sebuah produk tidak hanya bisa bekerja dengan baik, tetapi juga terasa cepat, intuitif, dan nyaman digunakan. Dalam proses development, saya menerapkan pendekatan yang berorientasi pada clean architecture, maintainability, performance, testing, serta memanfaatkan teknologi dan tools modern untuk membuat proses pengembangan lebih efektif.<br><br>Saat ini, saya membangun berbagai solusi web menggunakan teknologi seperti Laravel, PHP, PostgreSQL, React, Next.js, TypeScript, dan Tailwind CSS, sambil terus mengeksplorasi cara baru untuk menghasilkan software yang lebih praktis dan berkualitas.
